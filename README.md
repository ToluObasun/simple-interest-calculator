# simple-interest-calculator
A simple, lightweight script/application that calculates the simple interest earned or paid over a specific period based on a principal amount, annual interest rate, and time.

## Formula
The application utilizes the standard simple interest formula:

$$A = P(1 + rt)$$

Where:
* **$A$** = Total Accumulated Amount (Principal + Interest)
* **$P$** = Principal amount
* **$r$** = Annual interest rate (as a decimal)
* **$t$** = Time period (in years)

## Features
* Input validation for principal, rate, and time.
* Instant calculation of total interest and final balance.
* Clear and minimalist command-line/user interface.

## How to Use
1. Enter the **Principal amount** (initial investment or loan amount).
2. Enter the **Annual interest rate** (e.g., enter `5` for 5%).
3. Enter the **Time period** in years.
4. Run the script to view the calculated interest and final balance.
